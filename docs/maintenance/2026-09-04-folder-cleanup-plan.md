weeks of visual QA, a Kepler Fold regeneration, a wordmark swap, and at least

intermediate renders, Playwright tooling snapshots) that were either already
`.gitignore`d but left on disk, or were never added to `.gitignore` at all.

## Tier 3 — Tracked artifacts (140 files, 54 MB) — DECISION REQUIRED

Most of `artifacts/qa/`, `artifacts/audits/`, `artifacts/design/`, and
`artifacts/research/karve-digital-2026-08-13/` are **tracked** — they ARE the
visual evidence. Deleting them removes data from the git tree. Three options:

- **3A. Leave as-is.** 54 MB in git is cheap. The repo's history is the source
  of truth. Do nothing.
- **3B. Move out of repo.** `git mv` + move to a sibling archive folder
  (e.g. `D:/Personal Project/portofolio/_archive-2026-09-04/`), commit the
  move. Folder stays accessible but does not bloat the working tree.
- **3C. Strip from history.** `git filter-repo` or `bfg` to remove
  `artifacts/qa/`, `artifacts/audits/`, `artifacts/design/` from every commit
  on `master`. This rewrites history, so anyone with a clone must re-clone.
  Do **not** do this without explicit user approval and a fresh clone backup.

**Recommendation: 3A.** 54 MB is not worth the disruption. If a future
release-tag-driven archive becomes important, revisit then.

## Rollback plan

- **Tier 1** is fully reversible: `pnpm install` regenerates `node_modules`
  (we are not deleting it), `pnpm dev` regenerates `.next`, Kepler Fold
  regeneration scripts re-emit `_candidates` and `_build`, QA scripts
  re-emit the `*-profile/` dirs on next run. No git history is touched.
- **Tier 2** is one-way: once the audit dump is gone, the only copy of those
  files is whatever was already committed before today. Verify by running
  `git log --all -- "artifacts/audit-2026-08-16/*" | head` before deleting
  (expected: nothing — that dir was never committed).
- **Tier 3** is a git operation, fully reversible via `git reset --hard`
  (within reflog) or `git revert` for any commit that moves things around.
