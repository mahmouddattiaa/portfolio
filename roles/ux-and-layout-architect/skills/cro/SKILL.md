# CRO for this portfolio

Local adaptation of [Corey Haines CRO](https://github.com/coreyhaines31/marketingskills/blob/main/skills/cro/SKILL.md), consulted 2026-11-01. MIT notice: `../LICENSES.md`.

Read `.agents/product-marketing.md`. The audience is founders and CTOs arriving from hiring profiles, referrals, and search. The primary action is a qualified project inquiry.

Apply these criteria in order: five-second value clarity; locked headline prominence; one primary CTA; scannable content; proof near the action; objections addressed through the four FAQs; contact friction.

Map each criterion to a named component and state. Keep the complete H1, availability, primary CTA and four proof pills visible within the mobile target viewport. Use a calculated budget and flag browser validation as pending.

Preserve three form fields. Specify labels, validation, pending, success, failure, retry and direct-contact fallback. Do not invent a working backend or booked-call integration.

Do not rewrite source copy, add testimonials, invent results, propose experiments, or follow upstream links into other skills. Step 2 owns hierarchy; Step 3 owns responsive sizing.
